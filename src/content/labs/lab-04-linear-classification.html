Часть 3. Метрики: где легко обмануть себя

Матрица ошибок при пороге tt даёт четыре числа, из которых собираются все метрики:

precision=TPTP+FP,recall=TPR=TPTP+FN,FPR=FPFP+TN. \text{precision} = \frac{TP}{TP+FP},\quad \text{recall} = TPR = \frac{TP}{TP+FN},\quad FPR = \frac{FP}{FP+TN}.

ROC-кривая — точки (FPR(t),TPR(t))(FPR(t), TPR(t)) по всем порогам; PR-кривая — (recall,precision)(\text{recall}, \text{precision}). Посмотрим, что происходит с ними при росте дисбаланса классов.

Напоминание — матрица ошибок, F1F_1 и AUC. Модель выдаёт балл, порог tt превращает его в ответ, и каждый объект попадает в одну из четырёх клеток:

предсказано 1 предсказано 0
на самом деле 1 TPTP (верно найден) FNFN (пропуск)
на самом деле 0 FPFP (ложная тревога) TNTN (верно отвергнут)

Отсюда: precision — какая доля тревог оказалась настоящей, recall (он же TPRTPR, полнота) — какую долю настоящих единиц мы нашли, FPRFPR — какую долю нулей зря объявили единицами. Precision и recall тянут в разные стороны: объявив всех единицами, получим recall =1= 1 при мизерной precision. F1=2precision⋅recallprecision+recallF_1 = 2\,\frac{\text{precision}\cdot\text{recall}}{\text{precision}+\text{recall}} — их гармоническое среднее: оно мало, если мала хотя бы одна из величин.

AUCAUC — площадь под кривой; для ROC она равна вероятности того, что случайный объект класса 1 получит балл выше случайного объекта класса 0 (проверим это в домашней работе). У случайной модели ROC-AUC =0.5= 0.5, у идеальной — 11.

Часть 4. SVM: решение зависит только от опорных векторов

Прямая задача (опр. 3.9): min⁡12∥w∥2\min\frac12\|w\|^2 при yi(w𝖳xi+b)≥1y_i(w^{\mathsf T}x_i+b)\ge1. В двойственной задаче (теорема 3.11) появляются множители αi\alpha_i, и

w*=∑iαi*yixi. w^* = \sum_i \alpha_i^* y_i x_i .

Объекты с αi*>0\alpha_i^*>0 — опорные векторы; по условию дополняющей нежёсткости они лежат ровно на границе полосы. Все остальные в сумму не входят вовсе. Проверим это буквально: удалим их.

Напоминание — условие дополняющей нежёсткости. Это одно из условий Каруша–Куна–Таккера — необходимых условий минимума при ограничениях-неравенствах. Каждому ограничению gi(w)≤0g_i(w)\le0 отвечает множитель αi≥0\alpha_i\ge0, и в точке минимума обязательно αigi(w)=0\alpha_i\,g_i(w) = 0: либо множитель нулевой, либо ограничение выполнено как равенство.

Для SVM ограничение — это yi(w𝖳xi+b)≥1y_i(w^{\mathsf T}x_i + b)\ge1, поэтому: объект строго вне полосы (>1>1) ⇒\Rightarrow αi=0\alpha_i = 0 и в решении он не участвует; объект с αi>0\alpha_i>0 ⇒\Rightarrow отступ ровно 11, то есть он лежит на границе полосы. Отсюда и всё поведение метода: решение определяется горсткой пограничных объектов, а не всей выборкой.

Часть 5. Ядра

Определение 3.16: K(x,x′)=⟨φ(x),φ(x′)⟩K(x,x') = \langle\varphi(x),\varphi(x')\rangle для некоторого отображения φ\varphi. Критерий Мерсера: KK — ядро тогда и только тогда, когда матрица Грама ∥K(xi,xj)∥\|K(x_i,x_j)\| симметрична и неотрицательно определена.

Проверить это можно прямо: посчитать собственные числа матрицы Грама.

pts = rng.normal(size=(40, 2))
d2 = np.sum(pts ** 2, 1)[:, None] - 2 * pts @ pts.T + np.sum(pts ** 2, 1)[None, :]

candidates = {
    "линейное  x^T x'": pts @ pts.T,
    "полиномиальное (x^T x' + 1)^3": (pts @ pts.T + 1) ** 3,
    "RBF exp(-||x-x'||^2)": np.exp(-np.maximum(d2, 0)),
    "сигмоидное tanh(0.1 x^T x')": np.tanh(0.1 * pts @ pts.T),
    "НЕ ядро: ||x - x'||": np.sqrt(np.maximum(d2, 0)),
}
for name, G in candidates.items():
    lam_min = np.linalg.eigvalsh((G + G.T) / 2).min()
    print(f"{name:32s} min lambda = {lam_min:+9.4f}  ->  "
          f"{'ядро' if lam_min > -1e-8 else 'НЕ ядро'}")

Напоминание — NumPy: как рисуют карту решений. Приём встречается в каждом занятии дальше, поэтому разберём его один раз. Чтобы закрасить плоскость по ответу модели, нужно спросить её в каждой точке регулярной сетки:

  1. np.meshgrid(xs, ys) даёт две матрицы g1, g2 формы (200, 200) — координаты xx и yy каждого узла сетки;
  2. модель принимает матрицу «объекты--признаки», а не две матрицы, поэтому сетку разворачивают в список точек: g1.ravel() вытягивает матрицу в вектор длины 40000, а np.c_[a, b] склеивает два вектора в две колонки;
  3. полученные 40000 ответов сворачивают обратно в форму сетки: .reshape(g1.shape) — и такую матрицу уже понимает contourf.

Коротко: ravel — «разложить в строчку», reshape — «сложить обратно в нужную форму»; число элементов при этом не меняется.

def plot_boundary(ax, model, X, y, title):
    g1, g2 = np.meshgrid(np.linspace(X[:, 0].min() - .5, X[:, 0].max() + .5, 200),
                         np.linspace(X[:, 1].min() - .5, X[:, 1].max() + .5, 200))
    Z = model.decision_function(np.c_[g1.ravel(), g2.ravel()]).reshape(g1.shape)
    ax.contourf(g1, g2, Z, levels=[-1e9, 0, 1e9], colors=["#cfe8e4", "#f6ddc4"], alpha=.8)
    ax.contour(g1, g2, Z, levels=[0], colors="black", linewidths=1.8)
