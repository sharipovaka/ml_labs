Часть 1. Векторизация вместо циклов

Курс записан в матричных обозначениях: матрица «объекты–признаки» размера ℓ×n\ell\times n — это массив NumPy формы (l, n). Правило, которое сэкономит десятки часов: если вы пишете цикл по объектам выборки, почти наверняка есть векторизованная запись — короче и в десятки раз быстрее.

Проверим это на матрице попарных квадратов расстояний Dij=∥ai−bj∥2D_{ij} = \|a_i - b_j\|^2. Двойной цикл здесь не нужен, потому что

∥a−b∥2=∥a∥2−2⟨a,b⟩+∥b∥2. \|a - b\|^2 = \|a\|^2 - 2\langle a, b\rangle + \|b\|^2 .

Напоминание — NumPy: ось, срез, broadcasting и @. Четыре приёма, без которых дальше не обойтись. Пусть X имеет форму (l, n).

Ось. X.sum(axis=0) даёт nn чисел — по одному на признак, X.sum(axis=1) даёт ℓ\ell чисел — по одному на объект. Правило: axis указывает, какая ось исчезает.

Срез. X[i] — ii-й объект (строка), X[:, j] — jj-й признак (столбец).

Broadcasting. Ось длины 1 растягивается: (l, 1) + (1, k) даёт (l, k). Отсюда приём [:, None] — превращает вектор в столбец, [None, :] — в строку. Столбец плюс строка есть таблица всех попарных сумм, и всё это без цикла.

Матричное умножение. A @ B — произведение матриц, A * B — поэлементное. Путать их — самая частая ошибка первых недель.

Если что-то не сходится, первым делом печатайте .shape.

import time


def dists_loops(A, B):
    """Попарные квадраты расстояний двойным циклом -- эталон корректности."""
    D = np.empty((A.shape[0], B.shape[0]))
    for i in range(A.shape[0]):
        for j in range(B.shape[0]):
            diff = A[i] - B[j]
            D[i, j] = diff @ diff
    return D

Часть 3. Смотрим на данные глазами

Таблицу мы прочитали, но ещё не видели. Разведочный анализ (EDA, exploratory data analysis) — это не украшение отчёта, а способ найти в данных то, чего describe не показывает. Каждому вопросу отвечает свой тип графика:

Вопрос График Функция
как устроен отдельный признак гистограмма sns.histplot
как соотносятся категории столбики с разбивкой sns.countplot
различается ли доля классов между группами столбики средних с интервалом sns.barplot
как признак распределён внутри групп ящик с усами, скрипка sns.boxplot, sns.violinplot

Последний вопрос сегодня главный: именно карта корреляций найдёт нам то, что мы пока не заметили. Но начнём с распределений — и заодно познакомимся с библиотекой, которая рисует всё перечисленное.

Напоминание — seaborn: зачем ещё одна библиотека для графиков. matplotlib рисует массивы: вы сами разбиваете данные на группы, сами считаете агрегаты, сами подписываете легенду. seaborn — надстройка над ним, которая рисует таблицы: вы говорите, какой столбец по оси xx, какой по yy и какой столбец задаёт цвет, а группировку и подписи она делает сама.

import seaborn as sns

sns.histplot(df, x="age", hue="survived")   # df -- таблица, hue -- чем красить

Три вещи, которые стоит запомнить сразу:

  • hue — «разбей по этому столбцу и раскрась». Главный приём seaborn: почти в каждой функции он превращает один график в сравнение групп.
  • ax= — куда рисовать. Функции уровня осей (histplot, boxplot, countplot, barplot, violinplot, heatmap) принимают готовую ось matplotlib, поэтому свободно смешиваются с plt.subplots. Функции уровня фигуры (pairplot, catplot, jointplot) сами создают всю фигуру целиком — ax= им передать нельзя.
  • sns.set_theme() — меняет plt.rcParams, то есть оформление всех графиков, включая нарисованные чистым matplotlib.

Всё, что делает seaborn, можно написать и на matplotlib — просто вместо одной строки получится десять. Ниже мы посмотрим на обе записи одного и того же графика и сравним.

Категориальные признаки: сколько кого и какова доля выживших

Гистограмма отвечает на вопрос о числовом признаке. Для категориального (pclass, embarked, alone) нужны две разные картинки, и путать их нельзя:

Ящик и скрипка: распределение внутри групп

Столбик показывает одно число на группу — среднее. Чтобы увидеть всё распределение внутри группы, есть два графика:

  • ящик с усами (boxplot) — медиана, квартили, выбросы; компактно и сравнимо между группами;
  • скрипка (violinplot) — та же коробка плюс сглаженная плотность; видно форму, в том числе два горба, которые ящик показать не в состоянии.

Опция split=True у скрипки складывает две половинки одной группы — удобно, когда hue бинарный.

Матрица диаграмм: всё против всего

pairplot рисует сетку: по диагонали — распределение каждого признака, вне диагонали — диаграммы рассеяния для каждой пары. Это функция уровня фигуры: она создаёт всю сетку сама, поэтому ax= ей не передают. С corner=True рисуется только нижний треугольник — верхний повторял бы его зеркально.

Полезно как первый общий взгляд, но дорого: для nn признаков это порядка n2n^2 графиков. На широких таблицах берут подмножество столбцов, как здесь.

cols = ["age", "fare", "sibsp", "parch", TARGET]

Часть 6. Пропуски, выбросы и масштаб

Три вещи, которые надо сделать с числовыми признаками, — и в каждой есть ловушка.

Напоминание — квантиль, квартиль, IQR. Квантиль уровня qq — значение xqx_q, ниже которого лежит доля qq наблюдений: x0.5x_{0.5} — медиана, x0.99x_{0.99} — 99-й перцентиль. Квартили — квантили уровней 0.250.25, 0.50.5, 0.750.75, обозначаются Q1,Q2,Q3Q_1, Q_2, Q_3. Межквартильный размах IQR=Q3−Q1\mathrm{IQR} = Q_3 - Q_1 — ширина «средней половины» данных. Он устойчив к выбросам: пока экстремальных значений меньше четверти, границы Q1Q_1 и Q3Q_3 не сдвинутся, тогда как x¯\overline x и σ\sigma один выброс тянет за собой.

Часть 7. Честное разбиение и первый ориентир

Главное правило всего курса:

Все параметры предобработки — средние, дисперсии, медианы для заполнения пропусков, список категорий — вычисляются только по обучающей части и затем применяются к контрольной.

Иначе информация о контрольной выборке просачивается в обучение, и оценка качества оказывается завышенной. Насколько именно — измерим на занятии 5. Порядок действий: сначала делим, потом обрабатываем, а не наоборот.

Напоминание — стратификация. При случайном делении выборки доли классов в частях могут заметно разойтись — особенно если один класс редкий. Стратифицированное разбиение делит выборку внутри каждого класса отдельно, поэтому доли сохраняются. В sklearn это аргумент stratify=y. Для регрессии он не нужен (классов нет), а для классификации — практически всегда.

from sklearn.model_selection import train_test_split
