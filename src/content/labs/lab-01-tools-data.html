import time


def dists_loops(A, B):
    """Тот же результат двойным циклом -- эталон корректности."""
    D = np.empty((A.shape[0], B.shape[0]))
    for i in range(A.shape[0]):
        for j in range(B.shape[0]):
            diff = A[i] - B[j]
            D[i, j] = diff @ diff
    return D

Часть 2. Численный эталон: три способа решить систему

Второй инструмент курса — численный эталон: задача, точный ответ которой известен заранее. На ней проверяют не скорость, а правильность: если ваша реализация не воспроизводит известный ответ, дальше идти бессмысленно.

Возьмём матрицу Гильберта Hij=1/(i+j−1)H_{ij} = 1/(i+j-1) — знаменитый пример плохо обусловленной матрицы. Положим wtrue=(1,1,…,1)w_{\text{true}} = (1,1,\dots,1) и b=Hwtrueb = Hw_{\text{true}}. Теперь точный ответ известен, и можно честно измерить, сколько знаков теряет каждый способ решения Hw=bHw = b.

Напоминание — число обусловленности. cond(A)=σmax(A)/σmin(A)\mathrm{cond}(A) = \sigma_{\max}(A)/\sigma_{\min}(A) — отношение наибольшего сингулярного числа к наименьшему. Практический смысл: если cond(A)=10k\mathrm{cond}(A) = 10^{k}, то при решении системы с матрицей AA теряется примерно kk верных десятичных знаков из имеющихся шестнадцати. У вырожденной матрицы σmin=0\sigma_{\min} = 0 и cond=∞\mathrm{cond} = \infty. В NumPy: np.linalg.cond(A). Величина встретится ещё много раз — в занятиях 2, 3 и 9.

from scipy.linalg import hilbert

rows = []
for n in (4, 6, 8, 10, 12):
    H = hilbert(n)
    w_true = np.ones(n)            # точный ответ, который мы обязаны получить
    b = H @ w_true

    solvers = {
        "inv(H) @ b": lambda: np.linalg.inv(H) @ b,
        "solve(H, b)": lambda: np.linalg.solve(H, b),
        "lstsq(H, b)": lambda: np.linalg.lstsq(H, b, rcond=None)[0],
    }
    row = {"n": n, "cond(H)": np.linalg.cond(H)}
    for name, f in solvers.items():
        row[name] = np.abs(f() - w_true).max()
    rows.append(row)

table = pd.DataFrame(rows).set_index("n")
display(table.map(lambda v: f"{v:.1e}"))

Три вещи, которые надо сделать с числовыми признаками, — и в каждой есть ловушка.

Напоминание — квантиль, квартиль, IQR. Квантиль уровня qq — значение xqx_q, ниже которого лежит доля qq наблюдений: x0.5x_{0.5} — медиана, x0.99x_{0.99} — 99-й перцентиль. Квартили — квантили уровней 0.250.25, 0.50.5, 0.750.75, обозначаются Q1,Q2,Q3Q_1, Q_2, Q_3. Межквартильный размах IQR=Q3−Q1\mathrm{IQR} = Q_3 - Q_1 — ширина «средней половины» данных. Часть 8. Честное разбиение и первый ориентир

Главное правило всего курса:

Все параметры предобработки — средние, дисперсии, медианы для заполнения пропусков, список категорий — вычисляются только по обучающей части и затем применяются к контрольной.

Иначе информация о контрольной выборке просачивается в обучение, и оценка качества оказывается завышенной. Насколько именно — измерим на занятии 5.

Технически это делает Pipeline с ColumnTransformer: они запоминают параметры на fit и применяют их в transform. Порядок действий тоже важен: сначала делим, потом обрабатываем, а не наоборот.

Напоминание — стратификация. При случайном делении выборки доли классов в частях могут заметно разойтись — особенно если один класс редкий. Стратифицированное разбиение делит выборку внутри каждого класса отдельно, поэтому доли сохраняются. В sklearn это аргумент stratify=y. Для регрессии он не нужен (классов нет), а для классификации — практически всегда: иначе часть разброса оценки качества объясняется просто неудачным делением.
