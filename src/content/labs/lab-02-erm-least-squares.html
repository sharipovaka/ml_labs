Часть 2. МНК для одного признака

Модель a(x)=θ0+θ1xa(x) = \theta_0 + \theta_1 x, где xx — bmi. Минимизируем эмпирический риск с квадратичной функцией потерь:

Q(θ)=∑i=1n(θ0+θ1xi−yi)2=∥Xθ−y∥2,Q(\theta) = \sum_{i=1}^{n} (\theta_0 + \theta_1 x_i - y_i)^2 = \|X\theta - y\|^2 ,

где у матрицы XX первый столбец из единиц, второй — значения bmi. Минимум даёт решение нормальных уравнений X⊤Xθ=X⊤yX^\top X\,\theta = X^\top y, то есть θ=(X⊤X)−1X⊤y\theta = (X^\top X)^{-1} X^\top y.

x = df['bmi'].values
y = df['target'].values

X1 = np.column_stack([np.ones_like(x), x])    # столбец единиц + признак
theta = np.linalg.solve(X1.T @ X1, X1.T @ y)   # нормальные уравнения
print('θ по формуле:', theta)

lr = LinearRegression().fit(x.reshape(-1, 1), y)  # sklearn ждёт матрицу (n, 1)
print('sklearn:     ', np.array([lr.intercept_, lr.coef_[0]]))

Формула в лекции содержит обратную матрицу, но в коде систему решают через np.linalg.solve: это быстрее и точнее, чем явно вычислять inv(X.T @ X).

grid = np.linspace(x.min(), x.max(), 100)

plt.title(f'target ≈ {theta[0]:.1f} + {theta[1]:.2f}·bmi');

Как выглядит Q(θ)Q(\theta)? Это квадратичная функция: Q(θ)=θ⊤(X⊤X)θ−2θ⊤X⊤y+y⊤yQ(\theta) = \theta^\top (X^\top X)\,\theta - 2\,\theta^\top X^\top y + y^\top y. Нарисуем её линии уровня.

A, b, c = X1.T @ X1, X1.T @ y, y @ y
T0, T1 = np.meshgrid(np.linspace(theta[0] - 250, theta[0] + 250, 300),
                     np.linspace(theta[1] - 9, theta[1] + 9, 300))
P = np.stack([T0, T1], axis=-1)                     # сетка точек θ, форма (300, 300, 2)
Q_grid = np.einsum('...i,ij,...j->...', P, A, P) - 2 * P @ b + c

Q_min = np.sum((X1 @ theta - y) ** 2)

plt.xlabel('θ₀'); plt.ylabel('θ₁'); plt.title('Линии уровня Q(θ)');

Минимум единственный, линии уровня — эллипсы. Эллипсы сильно вытянуты: bmi не центрирован, и θ0\theta_0 с θ1\theta_1 «мешают» друг другу (можно увеличить наклон и уменьшить свободный член почти без потери качества). На лабораторной 3 увидим, что градиентному спуску от этого плохо.

Часть 3. Проверяем лекцию: градиент и нормальные уравнения

В лекции: ∇Q(θ)=2X⊤(Xθ−y)\nabla Q(\theta) = 2X^\top(X\theta - y). Сравним с численной производной Q(θ+hej)−Q(θ−hej)2h\dfrac{Q(\theta + h e_j) - Q(\theta - h e_j)}{2h}.

def Q(theta, X, y):
    r = X @ theta - y
    return r @ r

def grad_Q(theta, X, y):
    return 2 * X.T @ (X @ theta - y)

def num_grad(f, theta, h=1e-4):
    g = np.zeros_like(theta)
    for j in range(len(theta)):
        e = np.zeros_like(theta)
        e[j] = h
        g[j] = (f(theta + e) - f(theta - e)) / (2 * h)
    return g

theta_rand = rng.normal(size=2)
g_formula = grad_Q(theta_rand, X1, y)
g_numeric = num_grad(lambda t: Q(t, X1, y), theta_rand)
print('по формуле: ', g_formula)
print('численно:   ', g_numeric)
print('отн. ошибка:', np.linalg.norm(g_formula - g_numeric) / np.linalg.norm(g_formula))
resid = y - X1 @ theta
print('градиент в точке минимума:', grad_Q(theta, X1, y))
print('сумма остатков:           ', resid.sum())
print('остатки · bmi:            ', resid @ x)

В точке минимума ∇Q(θ*)=0\nabla Q(\theta^*) = 0, то есть X⊤(y−Xθ*)=0X^\top(y - X\theta^*) = 0: вектор остатков ортогонален каждому столбцу XX. Для столбца единиц это значит, что сумма остатков равна нулю — модель со свободным членом в среднем не завышает и не занижает прогноз. (Нули здесь «численные»: ~10−910^{-9} на фоне чисел порядка 10610^{6}.)

Итоги занятия

Что мы увидели:

  1. МНК — это решение нормальных уравнений X⊤Xθ=X⊤yX^\top X\theta = X^\top y; своя функция в четыре строки даёт те же коэффициенты, что LinearRegression.
  2. Формула градиента из лекции проверяется численно, а равенство ∇Q(θ*)=0\nabla Q(\theta^*) = 0 означает, что остатки ортогональны столбцам XX — в частности, их сумма равна нулю.
  3. Модель линейна по параметрам, а не по исходным величинам: добавив признак z=x12+x22z = x_1^2 + x_2^2 или степени v,v2v, v^2, мы получаем окружность и параболу, оставаясь в рамках линейной регрессии.
  4. Самая частая ошибка — забытый столбец единиц: прямая проходит через начало координат, и MSE заметно хуже.
