Часть 2. Чего KK-средних не умеет — и почему

Функционал ∑k∑i∈Ck∥xi−μk∥2\sum_k\sum_{i\in C_k}\|x_i-\mu_k\|^2 жёстко задаёт форму кластеров. Разбиение по ближайшему центру — это диаграмма Вороного, то есть кластеры всегда выпуклые и разделены гиперплоскостями. Кроме того, квадрат расстояния штрафует крупные кластеры сильнее мелких.

Трудный случай — вложенные кольца: там, где KK-средних заведомо бессилен.

Напоминание — ARI и AMI: как сравнивать разбиения. Кластеризация не знает меток, но здесь мы данные породили сами, поэтому можем сравнить найденное разбиение с истинным. Напрямую сравнивать номера кластеров нельзя — они произвольны: разбиение {1,1,2,2}\{1,1,2,2\} и {2,2,1,1}\{2,2,1,1\} одинаковы. Поэтому смотрят на пары объектов: согласны ли два разбиения в том, лежат ли объекты ii и jj вместе.

ARI (adjusted Rand index) — доля согласованных пар, поправленная на случайность: 11 — полное совпадение, 00 — как у случайного разбиения (не как у худшего!), отрицательные значения — хуже случайного. AMI (adjusted mutual information) — то же по смыслу, но через взаимную информацию разбиений; ведёт себя устойчивее, когда кластеры сильно разного размера.

Обе метрики требуют истинных меток, поэтому на реальной задаче кластеризации недоступны — там остаются силуэт и информационные критерии из части 4.

Напоминание — три альтернативы KK-средних. Иерархическая (агломеративная) — начинает с одноэлементных кластеров и шаг за шагом сливает ближайшие; форму кластеров не навязывает, подробно в части 5.

DBSCAN — кластер это область, где плотность точек выше порога: объект «внутренний», если в шаре радиуса ε\varepsilon вокруг него не меньше min_samples соседей, и связные внутренние объекты образуют кластер. Число кластеров не задаётся, находит кластеры произвольной формы и отдельно помечает шум, но плохо работает, когда плотность разных кластеров сильно различается.

Спектральная — строит граф соседства, берёт первые собственные векторы его матрицы Лапласа и кластеризует объекты уже в этом представлении. Так вложенные кольца становятся линейно разделимы. По духу это тот же переход в другое пространство, что и ядровой трюк в занятии 4.

                       g.normal([3, 0], 0.35, (n // 10, 2)),
                       g.normal([1.5, 3.5], 1.6, (8 * n // 10, 2))])
        y = np.r_[np.zeros(n // 10), np.ones(n // 10), np.full(8 * n // 10, 2)]
    elif case.startswith("анизотропные"):
        X, y = make_blobs(n_samples=n, centers=3, cluster_std=0.9, random_state=seed)
        X = X @ np.array([[0.6, -0.63], [-0.41, 0.85]])       # вытягиваем кластеры
    elif case.startswith("кластеры разной плотности"):
        X = np.vstack([g.normal([0, 0], 0.25, (n // 3, 2)),
                       g.normal([2.5, 0], 0.9, (n // 3, 2)),
                       g.normal([1.2, 3.0], 1.8, (n // 3, 2))])

        X, y = make_circles(n_samples=n, noise=0.06, factor=0.45, random_state=seed)

Часть 3. Смеси распределений и EM

Определение 7.6: плотность смеси p(x)=∑kwkpk(x)p(x) = \sum_k w_k\,p_k(x). Прямая максимизация правдоподобия сложна из-за логарифма суммы; EM (опр. 7.8) вводит скрытые переменные и чередует:

E-шаг — ответственности (опр. 7.11): γik=wkpk(xi)∑swsps(xi)\gamma_{ik} = \dfrac{w_k\,p_k(x_i)}{\sum_s w_s\,p_s(x_i)};

M-шаг — пересчёт параметров как взвешенных оценок с весами γik\gamma_{ik}.

Теорема 7.9: логарифм правдоподобия не убывает на каждой итерации. Проверим — это главный эксперимент занятия.

KK-средних как предельный случай EM

Возьмём сферические ковариации Σk=σ2I\Sigma_k = \sigma^2 I и устремим σ→0\sigma\to0. Ответственности γik∝wkexp⁡(−∥xi−μk∥2/(2σ2))\gamma_{ik} \propto w_k\exp\bigl(-\|x_i-\mu_k\|^2/(2\sigma^2)\bigr) превращаются в жёсткое отнесение к ближайшему центру, а M-шаг — в пересчёт средних. То есть KK-средних — это EM для сферической смеси при σ→0\sigma\to0.

Часть 4. Сколько кластеров

Меток нет, поэтому «правильное» KK выбирается косвенно:

  • метод локтя: Q(K)Q(K) убывает всегда, ищут точку излома;
  • силуэт: si=bi−aimax⁡(ai,bi)s_i = \dfrac{b_i - a_i}{\max(a_i, b_i)}, где aia_i — среднее расстояние внутри своего кластера, bib_i — до ближайшего чужого;
  • информационные критерии для смеси: AIC=−2ln⁡L+2p\mathrm{AIC} = -2\ln L + 2p, BIC=−2ln⁡L+pln⁡ℓ\mathrm{BIC} = -2\ln L + p\ln\ell.

Сравним все четыре на данных с известным ответом.

Напоминание — силуэт, AIC и BIC. Силуэт объекта si∈[−1,1]s_i\in[-1,1] сравнивает, насколько он «свой» в своём кластере: si≈1s_i\approx1 — он гораздо ближе к своим, чем к чужим; si≈0s_i\approx0 — он на границе двух кластеров; si<0s_i<0 — ему место в соседнем кластере. Качество разбиения — среднее sis_i; чем больше, тем лучше.

AIC и BIC — общие критерии выбора модели вида «минус подогнанность плюс штраф за число параметров pp»: AIC=−2ln⁡L+2p\mathrm{AIC} = -2\ln L + 2p, BIC=−2ln⁡L+pln⁡ℓ\mathrm{BIC} = -2\ln L + p\ln\ell. Чем меньше, тем лучше. Первое слагаемое всегда улучшается с ростом KK (больше компонент — выше правдоподобие), второе за это штрафует; минимум и есть компромисс. У BIC штраф растёт с размером выборки (ln⁡ℓ\ln\ell против 22), поэтому на больших данных он выбирает более простые модели, чем AIC. Это тот же принцип SRM, что и в занятии 6, только мера сложности — число параметров смеси.

Часть 5. Иерархическая кластеризация и эффект цепочки

Определение 7.15: агломеративный алгоритм начинает с ℓ\ell одноэлементных кластеров и на каждом шаге объединяет два ближайших. Способ измерения расстояния между кластерами (linkage) определяет всё поведение: single берёт минимум по парам, complete — максимум, ward — прирост QQ при слиянии.

Сравним все четыре способа между собой.

from scipy.cluster.hierarchy import dendrogram, fcluster, linkage as scipy_linkage

X_d = StandardScaler().fit_transform(X_d)

fig, axes = plt.subplots(2, 4, figsize=(17, 7))
for j, lk in enumerate(["single", "complete", "average", "ward"]):

    dendrogram(Z, ax=axes[0, j], no_labels=True, color_threshold=Z[-2, 2])
    axes[0, j].set_title(lk + ("  <- ваш вариант" if lk == "ward" else ""),
                         fontsize=10)
    lab = fcluster(Z, 3, criterion="maxclust") - 1

Часть 6. Кластеризация без меток

Настоящий разведочный сценарий: у нас есть таблица wine, но метки сорта мы прячем и кластеризуем только по 13 химическим признакам. А потом достаём метки и смотрим, что нашёл алгоритм.

from sklearn.datasets import load_wine

wine = load_wine()
X_true = StandardScaler().fit_transform(wine.data)
y_true = wine.target                     # спрятан от алгоритма, нужен только для проверки
print(f"{X_true.shape[0]} объектов, {X_true.shape[1]} признаков, "
      f"истинных сортов {len(np.unique(y_true))}")

rows = []
for K in range(2, 9):
    km = KMeans(K, n_init=10, random_state=RANDOM_STATE).fit(X_true)
    rows.append({"K": K, "Q": km.inertia_,
                 "силуэт": silhouette_score(X_true, km.labels_),
                 "AMI с сортом": adjusted_mutual_info_score(y_true, km.labels_)})
own = pd.DataFrame(rows).set_index("K")
display(own.round(4))
K_best = int(own["силуэт"].idxmax())
km_best = KMeans(K_best, n_init=10, random_state=RANDOM_STATE).fit(X_true)
print(f"выбрано K = {K_best} (по силуэту), истинных сортов {len(np.unique(y_true))}")

print("\nсопряжённость найденных кластеров и настоящих сортов:")
display(pd.crosstab(pd.Series(km_best.labels_, name="кластер"),
                    pd.Series(y_true, name="сорт")))
