Идея доказательства подсказывает, что проверять: ошибка в собственном базисе умножается на |1−2ηλi||1 - 2\eta\lambda_i|. При η=1/λmax\eta = 1/\lambda_{\max} множитель равен ровно единице — то есть граница должна быть точной, а не с запасом.

def gradient_descent(X, y, eta, n_iter=120):

Часть 2. Цена плохой обусловленности

При оптимальном постоянном шаге ошибка убывает как (κ−1κ+1)t\bigl(\frac{\kappa-1}{\kappa+1}\bigr)^t, где κ=cond(X𝖳X)=λmax/λmin\kappa = \mathrm{cond}(X^{\mathsf T}X) = \lambda_{\max}/\lambda_{\min}. Значит, число итераций до заданной точности растёт линейно по κ\kappa.

def design_with_cond(n_obj, p, kappa, generator):
    """Матрица X с заданным cond(X^T X) = kappa."""
    A = generator.normal(size=(n_obj, p))
    U, _, Vt = np.linalg.svd(A, full_matrices=False)
    return U @ np.diag(np.logspace(0, -0.5 * np.log10(kappa), p)) @ Vt


def iters_to_converge(X, y, tol=1e-6, max_iter=400_000):
    ev = np.linalg.eigvalsh(X.T @ X)
    eta = 1.0 / (ev.max() + ev.min())              # оптимальный постоянный шаг
    opt = np.linalg.lstsq(X, y, rcond=None)[0]
    theta = np.zeros(X.shape[1])
    for t in range(1, max_iter + 1):
        theta = theta - eta * grad_Q(theta, X, y)
        if np.linalg.norm(theta - opt) < tol * np.linalg.norm(opt):
            return t
    return np.nan

Часть 3. Мультиколлинеарность: решение перестаёт быть определённым

Признаки мультиколлинеарны, если столбцы XX почти линейно зависимы. Тогда у X𝖳XX^{\mathsf T}X есть собственное число, близкое к нулю, и по утверждению 2.8 малое возмущение данных даёт большое изменение решения:

∥δθ∥∥θ∥≤cond(X𝖳X)∥δb∥∥b∥. \frac{\|\delta\theta\|}{\|\theta\|} \le \mathrm{cond}(X^{\mathsf T}X)\, \frac{\|\delta b\|}{\|b\|}.

Посмотрим на это не через оценку, а напрямую: обучим модель на 300 бутстреп-выборках и нарисуем облако полученных решений.

Напоминание — бутстреп. Мы хотим знать, как сильно решение θ\theta пляшет от выборки к выборке. Для этого нужно много выборок, а у нас одна. Бутстреп (Эфрон, 1979) решает это так: новая выборка того же размера ℓ\ell набирается из имеющейся случайным выбором с возвращением, то есть какие-то объекты попадут в неё дважды-трижды, а какие-то не попадут вовсе (в среднем не попадает доля (1−1/ℓ)ℓ→e−1≈37%(1-1/\ell)^{\ell}\to e^{-1}\approx37\,\%). Повторив это BB раз и обучив модель на каждой такой выборке, получаем BB оценок θ\theta — по их разбросу и судят об устойчивости.

Идея в том, что имеющаяся выборка — лучшее, что у нас есть, приближение генеральной совокупности, поэтому пересэмплирование из неё имитирует повторный сбор данных. Одна строка кода: idx = rng.integers(0, l, l), дальше X[idx], y[idx].

Бутстреп встретится ещё дважды: в занятии 6 на нём построен бэггинг, и он же даёт доверительные интервалы там, где аналитической формулы нет.

Часть 4. Ridge и LASSO: что они делают с решением

Определение 2.9 и теорема 2.10: гребневая регрессия минимизирует ∥Xθ−y∥2+λ∑j≥1θj2\|X\theta-y\|^2 + \lambda\sum_{j\ge1}\theta_j^2, и решение равно (X𝖳X+λD)−1X𝖳y(X^{\mathsf T}X + \lambda D)^{-1}X^{\mathsf T}y, где DD не штрафует свободный член. Матрица X𝖳X+λDX^{\mathsf T}X+\lambda D положительно определена при любом λ>0\lambda>0 — даже если X𝖳XX^{\mathsf T}X вырождена.

LASSO (опр. 2.15) штрафует ∑|θj|\sum|\theta_j|. Явной формулы нет, но поведение качественно иное: решение становится разреженным. Посмотрим на регуляризационные пути.

Напоминание — регуляризационный путь. Это график всех коэффициентов θj(λ)\theta_j(\lambda) как функций силы штрафа — по одной кривой на признак, по горизонтали обычно λ\lambda в логарифмическом масштабе. Слева (λ→0\lambda\to0) — обычный МНК, справа (λ→∞\lambda\to\infty) — все коэффициенты стянуты в ноль. Смотреть на него стоит по двум причинам: видно, какие признаки «держатся» дольше всех (у LASSO — те, что зануляются последними), и видно, насколько устойчивы коэффициенты — если кривые двух признаков зеркально скачут, это та самая мультиколлинеарность из части 3.
