Задача 2. LASSO покоординатным спуском

Явной формулы для LASSO нет, но при фиксированных остальных координатах задача по одной координате решается точно. Обозначим r(−j)=y−∑k≠jxkθkr^{(-j)} = y - \sum_{k\ne j}x_k\theta_k; минимизируется ∥r(−j)−xjθj∥2+λ|θj|\|r^{(-j)} - x_j\theta_j\|^2 + \lambda|\theta_j|, и из условия на субградиент

θj=S(⟨xj,r(−j)⟩,λ/2)∥xj∥2,S(z,γ)=sign(z)max⁡(|z|−γ,0). \theta_j = \frac{S\bigl(\langle x_j, r^{(-j)}\rangle,\ \lambda/2\bigr)}{\|x_j\|^2}, \qquad S(z,\gamma) = \mathrm{sign}(z)\max(|z| - \gamma, 0).

Функция SS — «мягкий порог»: она обнуляет координату, если её вклад меньше порога. Отсюда и разреженность, которую мы видели на занятии.

Напоминание — субградиент. |θj||\theta_j| не дифференцируема в нуле, поэтому условие «производная равна нулю» неприменимо. Для выпуклой функции его заменяет субградиент: любой вектор gg, для которого f(z)≥f(θ)+⟨g,z−θ⟩f(z)\ge f(\theta) + \langle g, z-\theta\rangle при всех zz — то есть любая опорная прямая, лежащая под графиком. У гладкой функции субградиент один и равен градиенту, а у |θ||\theta| в нуле это весь отрезок [−1,1][-1, 1]. Условие минимума выпуклой функции: 00 принадлежит множеству субградиентов. Именно из-за «люфта» [−1,1][-1,1] в нуле у LASSO целый диапазон значений ⟨xj,r⟩\langle x_j, r\rangle даёт ровно θj=0\theta_j = 0 — так и получается разреженность.

Для лапласовского априорного p(θj)∝e−|θj|/bp(\theta_j)\propto e^{-|\theta_j|/b} получается LASSO с λ=2σ2/b\lambda = 2\sigma^2/b.

Напоминание — априорное распределение и MAP. В байесовском подходе параметр θ\theta считается случайным. Априорное распределение p(θ)p(\theta) — то, что мы думаем о нём до данных («веса скорее малы, чем велики»). По формуле Байеса p(θ∣X)∝p(X∣θ)p(θ)p(\theta\mid X) \propto p(X\mid\theta)\,p(\theta) получается апостериорное — то, что мы думаем после. Оценка MAP (maximum a posteriori) — точка его максимума:

θMAP=arg⁡maxθ[ln⁡p(X∣θ)+ln⁡p(θ)]. \theta_{\mathrm{MAP}} = \arg\max_\theta\bigl[\ln p(X\mid\theta) + \ln p(\theta)\bigr].

Первое слагаемое — то самое правдоподобие из занятия 2 (при p(θ)≡p(\theta)\equiv const получается обычный ММП), второе — штраф.
